# Calendario de Sitges 2026

Sitio estático pensado para GitHub Pages. `index.html` contiene el calendario completo y sus datos; no necesita compilación ni servicios externos.

## Actualizar sesiones

En `index.html`, modifica `films`, `venues` o `sessions` según corresponda. Cada sesión guarda su fecha, hora, duración completa y sala. Las selecciones de la persona usuaria quedan guardadas en el navegador local.

En móvil, el calendario conserva las seis columnas de días y se desplaza horizontalmente dentro del marco del calendario.
